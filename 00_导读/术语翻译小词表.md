# 术语翻译小词表

先看“可以怎样理解”，再跳到原题。比喻只负责帮你入门，具体条件以展开内容为准。字母 p、q、y 在不同公式里可能有不同角色，每次都要看本题定义。

## 看懂一次预测

| 术语 | 可以怎样理解 | 去哪里看 |
|---|---|---|
| token | 模型读写的一小块文字；不一定等于一个汉字或单词 | M01、T09 |
| tokenizer | 把文字切成 token 并映射到编号的工具 | T09 |
| 概率分布 | 把所有可能结果各分多少概率，合起来等于 1 | M01 |
| 条件概率 | 在已经知道某些信息后，一个结果出现的概率 | M01 |
| logits | 还没变成概率的原始分数，可正可负 | M04 |
| softmax | 把一组分数变成总和为 1 的概率 | M04 |
| log / ln | 对数；可把概率乘积转成加法。本资料通常用自然对数 | M01、M02 |
| 负对数似然 NLL | 给实际出现结果的概率取 log，再加负号，作为扣分 | M02 |
| 熵 | 这套概率有多不确定；完全确定时为零 | M09、M02 |
| 交叉熵 | 用预测概率给实际结果计分时的平均扣分 | M02 |
| KL 散度 | 用一套概率近似另一套概率时的额外代价，有方向 | M02、M03 |
| one-hot | 用一个 1 指出正确类别，其余位置为 0 | M05 |

## 看懂一次训练

|---|---|---|

| 梯度 | 参数或分数稍动时，损失怎样变化的局部信息 | M05 |
| 反向传播 | 从输出损失往前计算各参数梯度的方法 | M05、H01 |
| 学习率 | 根据梯度改参数时，更新幅度的系数 | M07 |
| batch | 一批一起计算的数据 | M08 |
| epoch | 按相应采样定义完整遍历一次训练数据 | SFT09 |
| checkpoint | 保存的模型或训练状态快照 | SFT10、X10 |

| mask / 遮罩 | 指定哪些位置不能被看见，或不参与某项计算的规则 | T05 |

## 看懂偏好与强化学习

| 术语 | 可以怎样理解 | 去哪里看 |
|---|---|---|
| policy / 策略 | 在当前条件下选择各动作或 token 的概率规则 | RL01 |
| rollout / 轨迹采样 | 按策略实际做一次，记录选择和结果 | RL01、RL15 |
| reward / 奖励 | 对结果或过程提供的评分；分数可能不可靠 | RL12 |
| return / 回报 | 按规定方式累计得到的奖励，可能包含时间折扣 | RL05 |
| advantage / 优势 | 这次选择的回报比某个基准好多少 | RL04、RL06 |
| actor | 负责选择动作、生成回答的模型 | RL03 |
| critic | 估计当前状态后续回报的价值模型 | RL03、RL05 |
| reference | 固定参考策略，提供原有概率基准 | P06 |
| chosen / rejected | 同题较优回答 / 较差回答 | P02 |
| margin | 希望好坏之间拉开的间隔，单位要看公式 | P08 |
| sigmoid | 把实数映射到 0—1 的 S 形函数，两端逐渐变平 | P04、P17 |
| clip | 在指定目标中裁剪某个数的范围，不等于一切变化都被硬限制 | RL04 |
| on-policy | 使用当前或按算法约定足够近的新策略采样的数据 | M11 |
| off-policy | 使用其他或较旧策略产生的数据 | M11 |
| KL 正则 | 在目标中用分布偏离代价约束模型变化 | P03 |

## 看懂系统与评测

| 术语 | 可以怎样理解 | 去哪里看 |
|---|---|---|
| embedding / 向量表示 | 把对象变成一组数字，便于学习和比较 | R04、B04 |
| 召回（检索阶段） | 从大量资料中先找出一批可能有用的候选 | R02 |
| 召回率（指标） | 真正需要找出的正例，有多少被找回 | E01 |
| rerank / 重排 | 对召回的候选进一步排序 | R06 |
| grounding | 回答或判断与具体外部证据对应 | V03 |
| KV cache | 生成时保留历史键和值，减少重复计算 | I02 |
| prefill / decode | 处理已有输入 / 逐步生成新 token | I01 |
| 幂等 | 同一操作重复提交，不重复叠加业务结果 | A06 |
| 终态 | 任务结束时可核验的实际系统状态 | A07 |
| 分布漂移 | 新数据的来源、特征或规则与以前发生变化 | SA11 |
| 冻结测试集 | 比较期间固定内容和规则、避免随意调整的评测材料 | E11 |

## 遇到公式时，按这个顺序读

先找“输入是什么、想优化什么”；再找每个符号的含义；把求和看成“把各项加起来”，把期望看成“按相应概率求平均”；最后才看导数。

读到 πθ(y|x)，可以先念成：“参数为 θ 的模型，在看到 x 后写出 y 的概率”。读到 E，可以先问：“这是对哪些题、哪些回答求平均？”

## OPD 家族：先记老师从哪里来

| 名称 | 先这样理解 | 从哪读 |
|---|---|---|
| OPD | 学生自己做，老师沿学生实际走过的步骤指导 | KD25、KD26 |
| OPSD | 同一模型加上训练参考解，成为信息更多的自教师 | KD27、KD28 |
| MOPD | 不同问题向不同领域专家学，再整合成一个学生 | KD29、KD30 |
| SDPO | 把程序、工具等详细反馈交给自教师，重新评价原来的尝试 | KD31 |
| EOPD | 保留 OPD，在老师不确定的位置额外加入正向 KL | KD32 |
| U-OPSD | 用多次回答的共识构造伪答案，再做自蒸馏；共识仍可能错 | KD33 |
| stop-gradient / sg | 这次更新把该量当固定数；不等于模型永远不变 | KD26、KD27 |
| 行为策略 | 真正生成这条训练数据的策略 | HP06 |

## 预训练：把一本书变成练习题

| 名称 | 先这样理解 | 从哪读 |
|---|---|---|
| NTP | 看前文，预测下一块文字 | PT01、PT02 |
| FIM | 先给前后两段，再让模型补中间；训练文本需要重排 | PT03 |
| packing | 把短文装进训练块，提高有效内容比例 | PT06 |
| DoReMi | 先用小模型探索各领域数据应该喂多少 | PT07 |
| warmup | 初期逐步提高学习率，帮助训练平稳启动 | PT10 |
| 梯度累积 | 多批分别计算，积累之后再更新一次参数 | PT11 |
| MTP | 除了下一个位置，还练更远的未来 token | PT15 |
| mid-training | 基础训练与最终后训练之间的能力强化阶段，定义需看报告 | PT16 |
| PPL / 困惑度 | 从平均预测扣分换算出的指标，需要统一计分单位再比较 | PT17 |
