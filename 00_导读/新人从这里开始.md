# 新人从这里开始

这套资料现在先教你看懂，再帮助你准备面试。第一遍不用背公式，也不用一次记住所有缩写。每题先读例子，能用自己的话解释发生了什么，再看一句“直答”；想继续研究时，展开公式与追问。

## 先建立一张地图：一个模型是怎样变成助手的？

### 1. 先会接着写

输入“我喝了一杯”，模型给下一块文字分配概率。大量文本训练，让它逐渐熟悉语言、知识表达和一些解题模式。这是理解语言模型的起点，见 M01。

### 2. 再知道什么叫“这次学得不好”

实际答案是“水”，模型却几乎不给“水”概率，就需要扣分。扣分规则叫损失，交叉熵是常见的一种。参数更新让平均损失逐渐下降。先读 M04、M09、M02，再读 M05、M07。

### 3. 给它更清楚的作答示范

会续写，不等于会按用户要求办事。SFT 用“问题—示范回答”教它怎样回答；LoRA 是减少一部分训练开销的更新方式。先读 SFT01、SFT03。

### 4. 再学会在多个回答里偏向更好的

同题两个回答，一份更好、一份较差，可以提供偏好反馈。DPO、SimPO 等方法据此改变生成倾向。能自己尝试并可靠评分时，还可以用强化学习。先读 P01、P06、P08、RL01、RL06。

### 5. 不知道就查，需要办事就调用工具

RAG 像开卷找资料；Agent 可以根据结果决定下一步动作。二者都有完整流程，模型只是其中一部分。先读 R01、A01。

### 6. 最后检查：真的更好了吗？

别只看训练扣分。还要看新题、真实用户任务、漏检误拒、响应时间和成本。E01 用坏苹果例子讲最常见的精确率和召回率。

## 第一轮只学这 20 题

| 步骤 | 题号 | 学完只需做到 |
|---|---|---|
| 模型怎样预测 | M01、M04、M09 | 解释 token、分数、概率和不确定性 |
| 怎样打分与学习 | M02、M05、M07 | 讲清交叉熵与 KL 的区别、更新往哪走 |
| 怎样读上下文 | T01、T02、T05、T04 | 讲清注意力、遮罩和 K/V 共享 |
| 怎样教它回答 | SFT01、SFT03 | 分清训练示范和减少可训练参数 |
| 怎样学好坏 | P01、P06、P08 | 分清偏好反馈、参考模型和 SimPO |
| 怎样自己尝试 | RL01、RL06 | 把奖励和组内比较讲成一个过程 |
| 怎样考、查、做 | E01、R01、A01 | 分清指标、查资料和调用工具办事 |

这 20 题是理解入口，不是 20 道高频题的统计结论。可以分成 7 次学习，每次完成表格一行，不规定必须一天学完。

**特别想弄懂交叉熵和 KL，直接从 M02 的红蓝球例子开始。**

## 每次怎样学，才不陷入背术语？

1. 先说这个方法想解决什么麻烦。例如“答案太长，总概率受长度影响”。
2. 按自己的话复述例子，把数字或对象换一下。例如红球 80% 改成 50%，会发生什么？
3. 读“直答”，把例子收束成一句较正式的回答。
4. 有余力再展开“公式、边界与追问”。不理解的符号先查词表；未学过的前置概念先跳回去。
5. 第二天先不看答案，解释一次。解释卡住的地方，才是下一步要补的地方。

P0/P1/P2 是原有岗位优先级，**不表示理解难度，也不意味着新人必须立即全部会**。第一轮完成后，再按目标岗位学习，最后用 48 道核心题做口述复习。

## 一个概念的“理解通过”标准

以交叉熵为例，你不必一开始就会求导，但应能回答：

- 模型给实际答案 90% 和 10% 概率，哪次扣分更多？——10% 那次。
- 已知红蓝球长期比例是 80/20，模型也报 80/20，还会每次都猜中吗？——不会，随机性仍然存在。
- 两套概率相同，KL 为 0，为什么交叉熵未必为 0？——后者还包括结果本身的不确定性。
- KL 很小，是否已经证明模型安全？——没有，它只描述指定分布比较，具体行为仍需评测。

能讲清这些，再进入公式推导，会比直接背定义更稳。


## 新增专题怎么接着学

理解交叉熵、KL 和 SFT 后，按需要选择：

- **蒸馏高级模型 / Agent 岗位：**KD25 → KD27 → KD29 → KD34，先辨清 OPD、OPSD、MOPD；再读 KD11、KD14、KD17、KD21 的轨迹与评测。
- **预训练入门：**PT01 → PT02 → PT05 → PT06 → PT08 → PT10 → PT11 → PT13 → PT17 → PT20，从训练样本走到实际训练过程。
- **后训练进阶：**HP01 → HP02 → HP04 → HP08，再按瓶颈补 SAPO、VESPO 或 SDPO。先说清想解决的问题，再比较新方法。

这些是入门 20 题之后的延伸路线，公式仍可按需展开。


## Agent 从入门到实战（1.4）

阅读器的“Agent 50 题”集中展示 A01—A14 与 AG01—AG36。先点订单演示，试着解释为什么“执行结果未知”不能改写成失败；再进入“Agent 入门 12 题”。

- **要做项目：**AG01—AG12 理解系统与工具；AG13—AG21 补上下文、记忆、交接与协同；AG31—AG35 做评测和作品。
- **要做训练：**AG25—AG29 先讲轨迹、监督与环境；接着读 KD25—KD34，按教师与反馈条件选择蒸馏方案。
- **要跟进前沿：**AG22—AG24 区分不同记忆学习方法；AG36 看训练与评测的 2026 阅读路线。先理解问题再追新缩写。

建议带着“Agent 可靠性小实验”阅读，用具体状态和执行证据检查自己的解释。研究条目与工程主线可以分开学习，不必第一轮就读完全部论文。
