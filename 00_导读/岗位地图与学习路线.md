# 岗位地图与学习路线

## 新人先走理解路线

第一次接触这些方法，先读“新人从这里开始.md”，完成 20 道入门题。本页的 7/14/30 天路线适合有基础后的岗位准备，不是要求新人按天赶完。先看例子、能用自己的话说清，再接受公式推导和项目追问。

## 你的四条主线

| 主线 | 应体现的能力 | 重点章节 | 最值得补的证据 |
|---|---|---|---|
| 后训练/内容安全 | 把反馈变成训练目标，控制漏放和误拒 | 04–09、项目 J01–J04 | 数据卡、DPO 对照、双侧评测和成本 |
| Agent/RAG 算法 | 知识获取、工具执行、记忆和故障恢复 | 09–11、J05–J06 | 证据级评测、终态基准与故障注入 |
| 模型评测/AI 平台 | 版本可比、统计可信、回归可定位 | 09、12–13、J07 | 冻结快照、配对差异和可重跑报告 |
| 驾驶人因/VLM 可靠性 | 部分可观测建模、视觉证据和闭环评价 | 14、J08、C08 | 图像干预、危险建议与本人论文贡献 |

这是基于已有报告的能力映射，不是实时岗位招聘清单。具体 JD、HC 与技术栈仍按投递时信息调整。

## 先修顺序

概率与梯度（01）→ 注意力与分词（02）→ 数据与 SFT（03–04）→ 偏好/强化学习（05–07）。

评测统计（09）支撑所有方向；内容安全（08）、RAG（10）、Agent（11）可按岗位穿插。推理/分布式（12–13）提供成本与工程理解；驾驶（14）形成差异化；传统基线（15）与手撕（16）用于补齐短板。

## 每题怎么学

1. **30–60 秒：** 用自己的话给结论，明确输入、输出和目标。
2. **2–3 分钟：** 补机制、公式或例子，解释关键条件。
3. **5 分钟追问：** 比较方案、指出失效、设计验证。
4. **项目落地：** 写下本人真实证据；没有则标实验计划。

背诵不是逐字复述。判断掌握的标准是：换一个数据条件或预算，你还能给出合理答案。

## 七天冲刺：已有项目、面试临近

| 天 | 主任务 | 当天验收 |
|---|---|---|
| 1 | 核对 J01–J10；读 M/T 核心 | 两分钟介绍项目；手算 CE 与 attention 维度 |
| 2 | SFT、LoRA、DPO | 推导 P03–P05；说清真实训练配置 |
| 3 | SimPO/KTO/GRPO | 比较 P11；解释零优势和 reward hacking |
| 4 | 安全与评测 | 讲清 79%→96% 口径；设计双侧评测 |
| 5 | RAG 与 Agent | 对真实失败逐层归因；讲超时恢复 |
| 6 | 工程/驾驶按岗位选 | KV 算例；视觉 grounding 或服务时延 |
| 7 | 一场 60 分钟模拟 | 记录五个错误，修三项最关键证据 |

## 十四天巩固：每天约 1.5–3 小时

第 1–2 天数学与 Transformer；第 3 天数据；第 4 天 SFT/LoRA；第 5–6 天 DPO/SimPO/KTO；第 7 天 PPO/GRPO；第 8 天安全；第 9 天评测；第 10 天 RAG；第 11 天 Agent；第 12 天推理/分布式；第 13 天驾驶交叉或目标 JD 加深；第 14 天模拟与复盘。

每天至少闭卷复述五题、做一个算例或错误分析，复习前一天的两道薄弱题。未完成时顺延，不把读完页数当掌握。

## 三十天形成岗位证据

| 阶段 | 阅读和实现 | 可审查交付物 |
|---|---|---|
| 第 1 周 | 建立理论主干；冻结数据切分；运行 CPU 练习 | 题目学习记录、数据卡、基线定义 |
| 第 2 周 | 按一个主线做小规模对照 | 训练/检索/Agent 配置、日志、真实结果 |
| 第 3 周 | 压力测试、消融、归因 | 鲁棒性矩阵、错误类别、成本分解 |
| 第 4 周 | 阈值或方案选择；复现和面试 | 一页项目总结、完整复现材料、三场模拟 |

首选补强方向是中文内容安全双侧评测；若正在投 Agent 岗，则改为三知识库任务终态与故障恢复基准。不要同月同时启动三个重训练项目而没有任何一项完成。

## 研究阅读优先级

先读 S08/S09/S10 的目标定义，接着 S12/S16 的 GRPO 与实现差异；安全读 S20–S24；RAG/Agent 读 S29/S31/S32；驾驶读 S42–S46。研究储备再读 S18/S19/S63/S64/S65/S66。

每篇只回答六件事：问题、信号、关键变化、对照、边界、能做的验证。来源索引列出了阅读入口和核查状态。

## 完成度自评

入门：能用一句话解释。能面试：能正确展开和追问。能证明：有推导、代码或真实实验。能维护：发现新证据后知道修改哪道题、保留哪些版本差异。


## Agent 蒸馏岗位补充路线（1.2）

先读 KD01、KD02、KD03、KD05，弄清教师信号；再读 KD07、KD11、KD17、KD21，理解学生状态、轨迹数据与评测。用 KD22 练一个完整项目回答。希望深入算法时，再比较 KD09 的 MiniLLM、KD10 的 GKD，以及 KD14/KD15 的 2026 预印本。CPU 数值练习与小项目设计在“03_代码实验/蒸馏数值实验与Agent小项目.md”。


## 新增专题怎么接着学

理解交叉熵、KL 和 SFT 后，按需要选择：

- **蒸馏高级模型 / Agent 岗位：**KD25 → KD27 → KD29 → KD34，先辨清 OPD、OPSD、MOPD；再读 KD11、KD14、KD17、KD21 的轨迹与评测。
- **预训练入门：**PT01 → PT02 → PT05 → PT06 → PT08 → PT10 → PT11 → PT13 → PT17 → PT20，从训练样本走到实际训练过程。
- **后训练进阶：**HP01 → HP02 → HP04 → HP08，再按瓶颈补 SAPO、VESPO 或 SDPO。先说清想解决的问题，再比较新方法。

这些是入门 20 题之后的延伸路线，公式仍可按需展开。


## Agent 从入门到实战（1.4）

阅读器的“Agent 50 题”集中展示 A01—A14 与 AG01—AG36。先点订单演示，试着解释为什么“执行结果未知”不能改写成失败；再进入“Agent 入门 12 题”。

- **要做项目：**AG01—AG12 理解系统与工具；AG13—AG21 补上下文、记忆、交接与协同；AG31—AG35 做评测和作品。
- **要做训练：**AG25—AG29 先讲轨迹、监督与环境；接着读 KD25—KD34，按教师与反馈条件选择蒸馏方案。
- **要跟进前沿：**AG22—AG24 区分不同记忆学习方法；AG36 看训练与评测的 2026 阅读路线。先理解问题再追新缩写。

建议带着“Agent 可靠性小实验”阅读，用具体状态和执行证据检查自己的解释。研究条目与工程主线可以分开学习，不必第一轮就读完全部论文。
