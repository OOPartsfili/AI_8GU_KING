## 如何读

1. **新人先走“20 题”路线**，或读“00_导读/新人从这里开始.md”。想弄懂交叉熵与 KL，可以直接打开 M02。
2. 每题先读场景和例子，试着换个数字或对象再解释一遍，然后读“直答”。
3. 在阅读器里点“我已读懂例子，继续看公式、边界与追问”再加深。也可以切到“完整阅读”，一次显示全部内容。
4. 遇到 token、logits、梯度、策略等词，先查“术语翻译小词表”。读完整个入门路线，再按岗位深入。
5. P0/P1/P2 表示岗位优先级，不是理解难度。48 道核心题适合建立直觉后的口述复习。
6. 教学例子用于理解方法，不代表个人经历或实际大模型训练成绩；个人项目数字仍需日志支持。

## 内容约定

- **事实**：原论文或官方文档支持的方法定义、明确条件下的结果。
- **教学推导**：从已注明的定义演算，保留假设与单位。
- **工程建议**：需要在自己的数据、预算与硬件上验证的选择。
- **研究观察**：已检索到的新研究；不等同于成熟方案或已复现结论。
- **个人背景**：根据用户提供的报告整理，实际面试仍以本人日志与材料为准。

原报告是岗位背景依据；其中论文名称、会议状态与技术结论在引用时另行核查。对尚未核实的背景数字，不新增或编造细节。

## 维护原则

Markdown 是正文唯一编辑源；每题使用固定编号。来源和题目索引分开维护，版本与核查日期可追踪。新增研究须说明它改变了哪一题的答案、在什么条件下成立，以及如何验证，避免只堆论文名称。

完成范围见“90_维护与来源/验收记录.md”；后续修改按“维护规范.md”执行。运行“验证与重建.ps1”可重新生成阅读器与索引。
