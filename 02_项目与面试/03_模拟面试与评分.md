# 模拟面试与评分

不冒充任何公司的真实题库。下面是按岗位能力要求设计的模拟流程。

新人请先完成入门路线，再用本页做自测。第一次可以不限时，先达到“能举例说明”的程度；60 分钟整场模拟放在原理和项目都准备好之后。

## 统一评分尺（每题 0–4 分）

| 分数 | 表现 |
|---:|---|
| 0 | 定义或方向错误，无法区分概念 |
| 1 | 能说名词和大意，追问后缺乏机制 |
| 2 | 原理基本正确，能举例或写关键式 |
| 3 | 条件、误区与实验验证完整 |
| 4 | 能结合本人真实证据，比较取舍并定位失败 |

对尚未实际做过的研究题，4 分可由准确推导、运行练习和扎实实验设计体现；不能用编造项目换高分。

## 场次一：后训练与内容安全（60 分钟）

| 时间 | 问题链 | 核心评分点 |
|---|---|---|
| 0–8 分钟 | J01 → J02 → J03 | 指标口径、个人贡献、数据切分 |
| 8–20 分钟 | P03 → P04 → P06 → P08 | DPO 推导、参考角色、SimPO β/γ |
| 20–30 分钟 | P12 → SA02 → SA05 | 好坏标签、双侧风险、多轮隔离 |
| 30–40 分钟 | RL06 → RL08 → RL10 | 组内优势、零信号、损失权重 |
| 40–50 分钟 | C04 | 对照、成本、消融和失败标准 |
| 50–60 分钟 | J04 → E05 | 真正归因和统计边界 |

**标准追问答案摘要：** 同题 Z 相消；DPO 的参考不负责判断语义对错；SimPO 平均差阈值是 γ/β；全组相同奖励没有相对学习信号；提高 precision 要同时看 recall。展开答案见相应题号。

## 场次二：Agent/RAG 与评测（60 分钟）

| 时间 | 问题链 | 核心评分点 |
|---|---|---|
| 0–8 分钟 | J05 → R09 | 三库边界和路由证据 |
| 8–20 分钟 | R04 → R05 → R06 → R11 | 稀疏/稠密、融合、重排、claim |
| 20–32 分钟 | A03 → A05 → A06 | schema 与语义、状态未知、幂等 |
| 32–42 分钟 | A09 → A11 → A13 | 记忆更新、信任边界、摘要 |
| 42–52 分钟 | C03 或 C06 | 终态、策略和故障注入 |
| 52–60 分钟 | E08 → E09 | 重复可靠性、judge 校准 |

**标准追问答案摘要：** reranker 无法找回从未召回的证据；格式正确不代表参数正确；写入超时先查状态；记忆需来源/时效/删除；pass^k 与 pass@k 目标不同。

## 场次三：基础、工程与驾驶交叉（60 分钟）

| 时间 | 问题链 | 核心评分点 |
|---|---|---|
| 0–12 分钟 | T01 → T02 → T06 | 维度、缩放、相对位置推导 |
| 12–24 分钟 | SFT03 → SFT06 → X02 | 低秩参数、量化精度、分片状态 |
| 24–34 分钟 | I03 → I08 → I10 | KV 算例、草稿验证、尾延迟 |
| 34–46 分钟 | V03 → V08 → V09 | grounding、开闭环与非反应式 |
| 46–55 分钟 | V11 → V12 → J08 | belief、EM、能力迁移 |
| 55–60 分钟 | F10 | 新论文的假设与验证 |

**标准追问答案摘要：** GQA 缓存按 KV 头数变；LoRA 冻结不等于无反向激活；精确 speculative decoding 依赖接受/残差规则；世界模型预测好看不证明规划安全；EM 不保证全局最优。

## 使用方法

先闭卷录音，再按题目检查错误；把不会的题记为“需复习”，能完成追问再标“已掌握”。每轮只选三个最影响岗位表现的问题补证据，避免只累计阅读时间。
