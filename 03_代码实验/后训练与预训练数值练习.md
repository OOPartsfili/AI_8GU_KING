# 后训练与预训练数值练习

目标是把 KD26、HP02—HP04、PT02、PT08、PT11 的数字算明白。这里的 CPU 程序只验证公式与样本组织；模型训练是后面的独立实验设计。

## 第一层：先把六件小事算对

| 练习 | 你应该看到什么 | 回到哪题 |
|---|---|---|
| 老师给 0.5，学生给 0.2 | 对数概率差约 +0.916；交换后为 −0.916 | KD26 |
| 固定上下文，枚举三个候选 token | 直接反向 KL 梯度、停止梯度优势的期望更新、有限差分三者一致 | KD26 |
| 两个新旧概率比为 2、0.5 | GSPO 几何平均为 1，算术平均为 1.25 | HP02 |
| 改变 SAPO 温度 | 在 r=1 处导数仍为 1，远离该点逐渐减弱 | HP03 |
| 把一个奖励维度放大 7 倍 | 在本练习的数值容差内，分别归一化后的优势不变；常数组不出现 NaN | HP04 |
| 标签移位、有效 token 与预算 | 目标比输入错后一位；损失按 token 加权；一次更新 65536 token | PT02、PT11 |

运行根目录“验证与重建.ps1”可一并检查。单独练习时，进入本目录，用可用的 Python 运行：

~~~text
python posttraining_pretraining_examples.py
python test_posttraining_pretraining.py
~~~

需要 NumPy。随机策略采样没有在此真正运行；为了避免蒙特卡洛噪声，OPD 例子显式枚举所有 token，再按学生概率加权。

### 怎样理解这个 OPD 检查

先固定老师与上下文，只改变学生的三个原始分数。第一种方法直接计算两套概率的反向 KL；第二种把“老师 logprob − 学生 logprob”当固定优势，计算每个可能选择的更新再取平均；第三种把一个原始分数稍微加减，观察 KL 的实际变化。

这能检查方向和停止梯度处理。它没有模拟前面动作改变后引发的后续状态变化，因此不能据此声称实现了完整序列 RL 或复现了 OPD 论文成绩。

## 第二层：预训练小模型对照方案

在具备相应训练资源后，可选择小规模文本续写模型，先完成一次能稳定下降并保存检查点的基础训练。以下是待执行方案。

1. **确定数据与切分。**选有权使用的小语料，按文档和近重复家族隔离训练与验证；记录 tokenizer 版本。
2. **先审一条样本。**逐位置打印输入、预测目标、attention mask 和有效 loss 位置，确认没有偷看答案或重复移位。
3. **固定一个预算。**记录模型规模、有效训练 token、优化器、学习率、上下文、微批次与累积次数。
4. **只改变一个因素。**例如原始数据与去重数据，或网页/代码的两种配比。去重后可以调整遍历次数，但要交代重复训练量并统一有效 token 预算。
5. **保存证据。**训练/验证曲线、分领域损失、生成样本、吞吐、显存、耗时、异常及恢复记录。
6. **给有边界的结论。**“在本数据、模型和预算下，方案 A 的某指标优于 B”；不要仅凭训练 loss 更低断言泛化更好。

## 第三层：有教师资源后怎么比较后训练

先选一个能验证终态的小任务，再逐步增加复杂度：示范 SFT → 单教师 OPD → 按实际信息条件考虑 OPSD 或 MOPD。统一学生起点、测试输入、总训练预算与教师调用成本。

有参考解才能做相应 OPSD 对照；有可靠领域专家和路由，才讨论 MOPD；有详细环境反馈再比较 SDPO。每个新步骤都同时测原能力是否遗忘、任务成功率和每成功任务成本。

**报告时分开三类工作：**已运行的数值检查、自己完成的模型实验、原论文结果。具体方法出处见 KD25—KD34、HP02—HP06、PT18、PT19。
