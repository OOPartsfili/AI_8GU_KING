# Transformer 手写与可视化设计依据

日期：2026-09-16。本轮以当前目录的优化版 1.4 为起点，没有使用旧的、一次性渲染全部正文的模板覆盖它。

## 用户参考材料实际看了什么

用户提供路径中的转义写法经目录检查，对应 `E:/1学习资料/阿里文档/HTML文档/模型hand_by_hand`。已阅读该目录 5 份 HTML 的教学结构、交互入口和实现：

- 01_tokenize_embedding：用 token→位置→查表逐步讲输入；区分查表向量与后续隐藏状态。
- 02_layer1_transformer：点击矩阵格子查看行乘列，开关因果遮罩和 softmax，按步骤追踪 Q/K/V 与输出。
- 03_48_layers_depth：层级切换、形状追踪，并区分示意曲线与真实模型数据。
- 04_gpu_deployment：参数变化驱动资源计算与布局，强调数值约束。
- 05_training_internals：按前向、loss、反向、累积和更新讲完整链路。

采用的教学方法是“可操作的小例子、参数变化后重新计算、逐步连接代码”。本库重新编写了小型数值演示，没有复制参考页的模型配置、真实权重声称、遥测脚本或外部资源依赖。

## 新增 8 个可视化

| 演示 | 可以操作什么 | 真正理解什么 |
|---|---|---|
| 矩阵投影 | 点输出格子 | 输入一行与权重一列怎样贡献结果 |
| 注意力 | 换示意头、开关遮罩和缩放、切分数/权重 | 打分→归一化→加权内容；未来遮罩的作用 |
| 拆头与合头 | 切换 1/2/4 头 | 数字顺序和轴语义，比只记 shape 更具体 |
| Block 数据流 | 在 7 个步骤间移动 | 归一化、注意力、残差、FFN 与最终预测如何连接 |
| RoPE | 改 Q/K 位置及频率 | 范数保持与点积里的相对位置 |
| KV Cache | 增加解码步数 | 缓存占用与省去的重复计算；新 Q 仍读全部 K |
| 交叉熵/KL | 改真实概率与预测概率 | 熵、平均扣分与额外扣分的区别 |
| LoRA | 改秩和缩放 | 冻结主路加小旁路；秩不够小时不一定省参数 |

均为有明确边界的教学模型：矩阵与概率直接计算；结构图只显示形状；缓存格数不能等同真实速度；二维旋转只展示一个通道对。

## 如何保留流畅性

- 保留轻量题目目录、按记录解析、正文/深读延迟挂载、搜索文本缓存和批量展开取消。
- 题目中的演示默认折叠，第一次主动展开才创建表格与控件；“展开全部题目”不会自动打开所有演示。
- 可视化中心一次只挂载 1 个演示，切换后旧节点和节点事件随页面释放。
- 只在用户改变输入时同步重算小数据；没有循环动画、持续定时器、全局 ResizeObserver 或网络请求。
- 代码下载按需解析嵌入资源，保持原目录副本和当前目录都能离线取得一致代码。
- 维护文件 reader_visuals.js / reader_visuals.css 在构建时合并入单文件 HTML，没有要求用户启动服务。

实测与上一版优化后的文件比较，结果写入 transformer-visual-qa.json。它包含四档页面宽度、交互检查及 4 倍 CPU 降速下的显示和交互测量；这比仅宣称“用懒加载所以不会卡”更可核查。具体测试条件及限制保留在报告中。
