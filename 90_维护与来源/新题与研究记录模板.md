# 新题与研究记录模板

本页可复制使用。尖括号中的内容由维护者填写，不能把空模板当作已完成题目。新增前先搜索已有问题，优先完善原题。

## 一道题的最小完整格式

~~~markdown
## 题号｜具体问题（优先级）

### 先用一个例子想明白

<具体问题是什么；旧做法哪里不方便；这个方法怎样处理。首次使用的术语用白话解释，提供可核对的例子。>

**直答：** <把已解释的机制收束成一句可复述的话。>

### 进一步：公式、边界与追问

**展开：** <定义符号；解释公式或流程；提供一个可核对的小例子。>

**追问：<面试官会进一步问什么？>** <这里必须给出答案，或明确可运行的练习及预期结果。>

**易错：** <最容易混淆的概念、失效条件或错误归因。>

**依据：** <已登记的来源编号；指出适用版本和原文位置。>
~~~

实际题号采用固定前缀和两位数字，如 P19；同一题号不随排序改变。优先级填写 P0、P1 或 P2。若一个主题需要超过 99 题，先升级编号解析规则，不要悄悄生成无法进入索引的新格式。

## 新研究记录卡

| 字段 | 填写要求 |
|---|---|
| 标题、作者、URL | 用原始来源核对，不照抄二手译名 |
| 版本与日期 | 发布、修订、此次核查日期分别填写 |
| 发表状态 | 作者自述与官方会议决定分开；无证据就写未核实 |
| 想解决的问题 | 旧方法在哪个具体条件下出错或成本过高 |
| 学习信号 | 数据、偏好、奖励或教师反馈来自哪里，怎样检查可靠性 |
| 核心变化 | 公式、目标函数、训练流程或系统部件改变了什么 |
| 公平比较 | 模型、数据、token、候选数、训练/推理预算是否一致 |
| 结果范围 | 指标、样本数、基线、误差与适用条件；不只摘最高分 |
| 失效与反例 | 新增代价、负面结果、没测的情形、证据不足处 |
| 影响哪些题 | 填已有题号，说明替换、补充还是暂不采用 |
| 最小验证 | 可在现有资源上验证哪条机制；什么结果会反驳预期 |
| 当前证据 | 明确区分读过原文、跑过代码、复现结果和未验证 |
