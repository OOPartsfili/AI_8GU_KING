# 18 · 后训练算法进阶与 2026 研究地图

**先把训练拆成三件事：从哪里取得反馈，怎样把反馈算成更新信号，怎样稳定地执行更新。**有些新方法改教师，有些改奖励归一化，有些改概率比权重。它们改动的位置不同。

核查基准日：2026-09-15。本章补齐 2025—2026 年有一手来源的方法；“较新”不等于“对所有任务最好”。OPD、OPSD、MOPD、SDPO、EOPD、U-OPSD 的完整比较在 KD25—KD34；本章重点讲策略优化的新改动。

| 瓶颈 | 代表方法 | 本章入口 |
|---|---|---|
| 同组奖励全相同、长回答计分失衡 | DAPO、Dr. GRPO | HP01 |
| 少数 token 概率比异常，整段更新不稳 | GSPO | HP02 |
| 硬剪切过于突然，仍想保留合适的更新 | SAPO | HP03 |
| 多个奖励先相加，差异被压掉 | GDPO | HP04 |
| 异步采样的数据变旧，概率比方差过大 | VESPO | HP05 |
| 分不清采样模型、教师和参考模型 | 数据与策略版本管理 | HP06 |
| 训练越来越会钻评分规则 | 验证器、过程反馈与对照实验 | HP07 |

第一遍按 HP01 → HP02 → HP04 → HP08 阅读。术语卡住时回到 RL04、RL06 和 KD26。以下教学算例不对应论文实测结果。

<a id="HP01"></a>
## HP01｜DAPO 和 Dr. GRPO，到底改了 GRPO 哪些地方？（P0）

**先看例子：**同一道题学生试四次，全对或全错。只比较这四次“谁更好”，就没有相对差异。另一道题有人写十个词，有人写一百个词，损失怎么算平均，也会改变每个词的训练权重。

**直答：**DAPO 是包含采样、剪切、损失聚合和超长处理的一套训练改进；Dr. GRPO 则分析并调整长度与难度相关的归一化偏差。两者都不能只记成“改了一个分母”。

### 进一步：公式、边界与追问

| DAPO 的改动 | 想解决什么 |
|---|---|
| Clip-Higher | 分开上下剪切范围，让部分低概率动作有更大的上调空间 |
| Dynamic Sampling | 对原方法关注的同组结果无差异问题，重新筛选/补充有学习信号的样本 |
| Token-Level Policy Gradient Loss | 按有效 token 聚合，改变长短回答的权重 |
| Overlong Reward Shaping | 改善达到长度上限时的训练信号 |

Dr. GRPO 的要点包括避免按每条回答长度归一所引入的偏差，以及重新审视按组奖励标准差缩放。具体分母与例子见 RL10。（S14、S15）

**追问：去掉全对题，是不是它们永远不值得训练？**这是某种相对优势估计缺少信号时的采样设计，不是对题目价值的普遍判断；换成教师分布监督仍可能有细粒度差异。

**追问：把输出超长都算错，有什么问题？**可能把“过程基本正确但被系统截断”混成“推理错误”，还可能教出投机的长度策略。应记录截断率、真实任务完成率和长度分布。

<a id="HP02"></a>
## HP02｜GSPO 为什么把概率比放到整段回答上看？（P1）

**先看例子：**两个 token 的新旧概率比是 2 和 0.5。单看第一个变化很大，但两步的乘积是 1。GSPO 用整段回答的平均对数变化来形成统一权重，希望减弱少数异常 token 对训练的干扰。

**直答：**GSPO 是 Group Sequence Policy Optimization。它用长度归一化的序列概率比进行策略优化和剪切，使同一回答内的 token 共享序列层面的更新尺度。

### 进一步：公式、边界与追问

先定义逐 token 新旧策略概率比：

$$r_{i,t}=\frac{q_\theta(y_{i,t}\mid h_{i,t})}{q_{\mathrm{old}}(y_{i,t}\mid h_{i,t})}$$

再取几何平均：

$$s_i=\exp\left(\frac{1}{L_i}\sum_t\log r_{i,t}\right)$$

这里 Lᵢ 是有效回答长度。2 与 0.5 的几何平均为 1，而算术平均为 1.25，二者不能互换。

**追问：这个 s 就是标准整段重要性采样权重吗？**完整序列概率比是各 token 比值的乘积；GSPO 额外取了长度归一化，改变了该量。它是稳定化的目标设计，不应直接声称仍为任意序列期望提供无偏修正。

**追问：为什么还要讨论缺点？**统一权重也可能因为少数异常位置而抑制同一段里的其他有用位置。应看概率比分布、有效更新比例与最终任务表现，而非只看训练曲线平滑。依据 S96，2025 年原论文。

<a id="HP03"></a>
## HP03｜SAPO 的“软门控”，比硬剪切多做了什么？（P1）

**先看例子：**控制更新像踩刹车。硬剪切在某些方向超过阈值后停止继续推动；软门控则逐渐减小更新力度，让接近旧策略的有效信号继续发挥作用。

**直答：**这里的 SAPO 指 Soft Adaptive Policy Optimization。它用温度控制的平滑函数替代硬剪切，并区分正、负优势的温度，以调整异常概率比对更新的影响。

### 进一步：公式、边界与追问

把概率比记作 r，一种论文中的门控形式是：

$$f(r)=\frac{4}{\tau}\sigma\left(\tau(r-1)\right)$$

τ 为正值，正、负优势可以选不同 τ；σ 是 sigmoid。目标中的对应项为 f(r)A。设计使 r=1 时对 r 的导数为 1，与未剪切项 rA 在该点的梯度尺度一致。

**追问：软门控就完全没有梯度变小的问题吗？**不是。远离 1 时它有意减弱更新，极端数值下仍可能非常小。“平滑”描述变化方式，不是所有样本都保持同样的学习力度。

**追问：SAPO 和蒸馏温度有关吗？**名字都叫温度，但这里调的是策略更新门控，KD03 的温度调的是概率软化。不要把取值直接互抄。

**名称提醒：**本题依据 S97（2025 年 Soft Adaptive Policy Optimization）；同缩写的其他 Agent RL 论文不自动属于这个算法。

<a id="HP04"></a>
## HP04｜GDPO 为什么要把多个奖励先分别归一化？（P1）

**先看例子：**给回答打两项分：“任务完成度”范围是 0—100，“格式正确”是 0—1。直接相加时，格式差异容易被大尺度分数盖住；再按总分归一化，还可能把不同奖励组合压成很相似的优势。

**直答：**这里的 GDPO 是 Group reward-Decoupled Normalization Policy Optimization。它先在同题采样组内分别处理每项奖励，再合并优势，并进行批次尺度的归一化，保留更多多奖励差异。

### 进一步：公式、边界与追问

用 j 表示同题第 j 个回答，k 表示奖励维度：

$$a_{j,k}=\frac{r_{j,k}-\mu_k}{\sigma_k+\epsilon}$$

$$b_j=\sum_k a_{j,k}$$

再对整个训练批次的 b 作一次中心化和尺度调整。这是教学简写；实现必须规定奖励维度无变化时的处理，不能除以零。（S98，2026-01 原论文）

**追问：分别归一化后，奖励就同样重要了吗？**不等于业务上同样重要。归一化改变数值尺度，业务权重和约束仍需明确；给某项加权是额外配置，不能默认为原论文的等权目标。

**追问：安全能和正确率随便加权交换吗？**一些硬约束需要单独检查。平均奖励再高，也可能掩盖低频严重错误。应展示每项指标和违反约束的案例。

**名称提醒：**这不是另一篇用于扩散语言模型的 Group Diffusion Policy Optimization，检索时需附完整名称与编号。

<a id="HP05"></a>
## HP05｜VESPO 为什么关心“数据已经过时了”？（P2）

**先看例子：**采样机器还在用昨天的模型做题，训练机器已经更新了很多轮。昨天模型爱写的答案，今天模型未必还会这样写；把旧数据当成今天刚生成的数据，更新就可能不稳。

**直答：**VESPO 针对异步采样与训练/推理差异造成的 off-policy 更新，研究如何在序列层面平滑调整重要性权重，用可分析的方差控制稳定训练。

### 进一步：公式、边界与追问

S99 的 2026-05 v3 从变分形式推导序列权重的重塑函数，区别于简单逐 token 剪切或直接把整段概率比做长度归一化。本题只讲问题与机制，不把简化示意冒充完整实现。

**追问：off-policy 等于离线数据集训练吗？**不等于。一个一直在线采样的系统，也会因为队列积压、模型版本延迟或推理实现差异，出现采样分布与当前训练策略不一致。

**追问：用了 VESPO 就可以无限复用旧数据吗？**不能。需要记录样本年龄、实际采样 logprob、有效样本量、权重尾部和任务表现；大偏移下还可能必须丢弃数据或刷新采样。

**相关：**M11 讲重要性采样直觉；HP02、HP03 讲另外两种更新稳定化思路。具体比较应固定异步程度和训练预算。

<a id="HP06"></a>
## HP06｜训练里几个“模型”，为什么不能都叫旧模型？（P0）

**先看例子：**学生采样用版本 A，训练已经到版本 B，老师是一个代码专家，参考策略则是训练开始时的模型。这四者有不同职责，记混了就会算错概率比或 KL。

**直答：**明确区分当前训练策略、产生这条数据的行为策略、提供指导的教师、用于约束偏移的参考策略。它们可能共享权重，也可能完全不同，算法要按实际角色写。

### 进一步：公式、边界与追问

| 角色 | 负责什么 | 需要记录 |
|---|---|---|
| 当前策略 | 被优化的学生 | 训练步骤、当前概率 |
| 行为策略 | 真正生成样本 | 采样版本、温度、截断和原 logprob |
| 教师 | 提供分布、示范或反馈 | 教师版本、输入上下文、路由 |
| 参考策略 | 定义约束或比较基准 | 是否固定、更新规则、预计算条件 |

**追问：模型权重相同，新旧概率为什么还可能不同？**采样温度、词表截断、精度、注意力实现、输入模板或 MoE 路由等都可能不同。先核对概率对应的分布，不能简单把差值都归因于模型学习。

**追问：只保存生成文本够吗？**对基础文本 SFT 往往可以；要严格做行为策略修正，还需要采样概率与配置。实际支持什么修正取决于训练器。本题依据 S91、S99，结合工程接口梳理。

<a id="HP07"></a>
## HP07｜更强的优化算法，能补救不靠谱的奖励吗？（P0）

**先看例子：**给客服模型的评分规则是“包含‘已解决’就加分”。模型学会每次都说“已解决”，即使没有调用任何工具，训练奖励也会飞涨。

**直答：**优化器只能更有效地追逐给定信号；信号有漏洞时，训练越有效，偏离真实任务也可能越快。需要把奖励、执行验证、教师反馈和独立评测一起设计。

### 进一步：公式、边界与追问

可把反馈分成三层：结果是否正确；过程是否满足依赖和约束；失败反馈能否解释哪里出了问题。标量结果适合直接比较，详细反馈可以作为 SDPO 等方法的输入，但反馈本身也需验证。

**追问：有了逐 token 教师监督，就解决信用分配了吗？**它提供更细的指导，但教师也可能误判。更密集不自动等于因果上正确的归因，尤其在工具报错和错误上下文后，见 KD14、KD31。

**实验建议：**固定学生与任务，比较只有结果奖励、增加详细反馈、增加可靠教师指导；单独统计奖励上涨但真实成功率下降的样本。不要把教师打分直接当作独立测试真值。依据 S14、S94；方案为教学设计。

<a id="HP08"></a>
## HP08｜面对“最先进后训练算法”，面试如何给出有判断的回答？（P0）

**先看例子：**如果瓶颈是没有正确示范，换一个更平滑的剪切函数未必有用；如果瓶颈是异步采样太旧，增加教师数量也未必有用。算法名称必须对应具体问题。

**直答：**我会先判断反馈可得性、失败类型和算力限制，再选对应改动；用固定起点、任务切分和总预算的实验，验证它是否改善目标能力。

### 进一步：公式、边界与追问

| 现有条件或瓶颈 | 值得比较的方向 |
|---|---|
| 教师文本可得，基础行为还没学会 | 轨迹 SFT / 序列蒸馏 |
| 学生自己的路径上缺少指导 | OPD / GKD |
| 有训练参考解 | OPSD 与答案 SFT 的信息对等比较 |
| 多个领域专家需要整合 | MOPD |
| 工具或程序返回详细失败信息 | SDPO |
| 组奖励、长回答、超长截断问题 | DAPO / Dr. GRPO |
| 策略概率比异常或硬剪切失效 | GSPO / SAPO |
| 多维奖励被混合抹平 | GDPO |
| 异步系统的采样偏移严重 | VESPO |

**追问：最新研究到什么时间？**本轮按 2026-09-15 检索，蒸馏区已纳入 2026 年 8 月 U-OPSD；其他章节保留 SOD、SEED、EOPD 等当年研究。条目注明具体来源和版本，不能据此声称已经穷尽所有新论文。

**最小实验证据：**同一学生起点；相同数据与反馈信息；训练及教师查询成本；多种子或重复评测；泛化与遗忘；只去掉关键改动的消融。没有这些条件，排行榜分数不足以回答“为什么更好”。依据本章各题来源及 E07、E09。
