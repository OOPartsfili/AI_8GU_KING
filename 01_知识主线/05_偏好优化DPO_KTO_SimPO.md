# 05 偏好优化：DPO、KTO 与 SimPO

这一章讲“同题有很多回答，怎样让模型更偏向好的”。先读 P01、P02、P06，再看 DPO 和 SimPO。P03–P05 的推导依赖 M02 的 KL 与 M05 的梯度；读不顺时先回到小例子。

<a id="P01"></a>
## P01｜RLHF、奖励模型与偏好优化是什么关系？（P0）


### 先会写答案，再学哪些答案更受认可

同一个问题，模型可能给出许多通顺但质量不同的回答。RLHF 就是利用人的反馈调整这种选择倾向。

经典路线先训练一个奖励模型，像学出来的评审员，再根据它的分数优化生成模型。DPO 则在特定数学假设下，直接用好坏回答对训练生成模型，不另训练独立评审员。

**直答：** 人类反馈提供好坏标准，奖励模型把标准变成分数，策略优化调整模型怎样生成；DPO 提供了直接从偏好训练生成模型的一条路线。

### 进一步：公式、边界与追问

**本章进阶约定与范围：**

定位：后训练与内容安全主投岗位的核心章节。先能说清“数据有什么反馈”，再谈算法。x 为同一问题，y_w/y_l 为较优/较差回答，π_ref 为固定参考策略。

**技术表述：** RLHF 利用人类反馈优化模型。经典流程先从偏好训练奖励模型，再优化策略；DPO 等方法用特定推导把偏好学习直接写成策略损失。

**展开：** 奖励模型回答“哪个回答更好”，策略模型负责生成。人类偏好数据、评审模型标签与程序可验证奖励是不同反馈来源，可靠性不能混同。

**追问：DPO 没有显式 reward model 就没有 reward 吗？** 它通过策略与参考策略的 log 概率比定义隐式奖励，不额外训练一个独立评分网络。

**易错：** RLHF 是方法框架，不等于 PPO 单个优化器。依据：S08、S11。

<a id="P02"></a>
## P02｜为什么偏好对必须是同一个问题？（P0）


### 比较两篇作文，题目应该相同

拿“解释交叉熵”的好回答和“写旅游攻略”的差回答相比，不容易判断模型该学到什么：差异可能来自题目本身。

偏好对通常针对同一问题、同一上下文，标记哪份更好。chosen 是较优回答，rejected 是较差回答，不代表一份完美、一份毫无价值。

**直答：** 同题比较尽量排除问题和条件差异，让训练信号集中到回答质量；标签还应说明依据，避免只学到长度或格式捷径。

### 进一步：公式、边界与追问

**技术表述：** 要比较相同条件下的回答质量，才能把排序归因于回答选择而非题目难度或任务差异。

**展开：** 同一个 prompt、工具条件、上下文、政策版本下构造 chosen/rejected；控制明显的格式、长度和语种捷径。偏好不明确时允许平局、丢弃或保留不确定性，不强行二选一。

**追问：内容安全里所有拒答都当 chosen 行吗？** 不行。正常请求的合理回答、危险请求的恰当处理、模糊请求的澄清都应覆盖。

**易错：** “人工通过/拦截”常是单样本业务标签，不能未经语义核查直接拼成同题偏好对。

<a id="P03"></a>
## P03｜DPO 是怎么从 KL 约束目标推出来的？（P0）


### DPO 推导先从一个朴素愿望开始

我们想让模型多写高质量答案，但又不希望它为了迎合评分而彻底变样。因此目标中有两部分：回答越好越加分，偏离参考模型的概率分布越多越扣分。

这里的 KL 就是 M02 讲过的分布差异量，不是在逐个比较参数。β 控制这项偏离惩罚的力度。

推导会得到：理想模型在原有倾向上，更多偏向高奖励回答。再把这个关系倒过来，就能用“新模型相对参考模型的概率变化”表达隐式奖励。

**直答：** DPO 从“提高奖励，同时惩罚偏离参考策略”出发，先求理想策略与奖励的关系，再把奖励改写成模型概率比，转成直接可训练的偏好损失。

### 进一步：公式、边界与追问

**技术表述：** 先求带参考策略 KL 惩罚的最优策略，再反解奖励，放入偏好概率模型。

固定 x，考虑：

$$\max_\pi\ \sum_y\pi(y|x)r(x,y)-\beta
\sum_y\pi(y|x)\log\frac{\pi(y|x)}{\pi_{\rm ref}(y|x)},\ \beta>0.$$

对概率归一化引入拉格朗日乘子，令对 π 的导数为零：

$$r-\beta(\log(\pi/\pi_{\rm ref})+1)+\lambda=0.$$

归一化后得到：

$$\pi^*(y|x)=\frac{\pi_{\rm ref}(y|x)e^{r(x,y)/\beta}}{Z(x)}$$

$$r(x,y)=\beta\log\frac{\pi^*(y|x)}{\pi_{\rm ref}(y|x)}+\beta\log Z(x).$$

**追问：假设是什么？** 参考策略在相关输出上有支持；奖励有限且可归一化；这是理想策略空间中的最优关系，有限神经网络训练不保证达到该最优解。

**易错：** β 在这个目标中是 KL 惩罚系数，不能把“β 越大”机械解释成“越激进”。依据：S08。

<a id="P04"></a>
## P04｜DPO 损失怎么写，为什么 Z 消失？（P0）


### 原模型已经喜欢的答案，和新训练学到的偏好

假设原模型就很喜欢模板化长回答。DPO 不只看当前模型觉得哪个答案更可能，还看这个倾向相对于参考模型改变了多少。

损失里的 sigmoid 可以先理解成把差值转成“偏好较优答案”的分数，差值越大，训练扣分越小。Z 是让概率总和为 1 的归一化项；同一个问题下两份回答共享它，相减时就抵消了。

**直答：** DPO 比较当前模型与参考模型各自对同题两个回答的概率差，再推动较优回答在这个相对比较中占优势；共享的归一化项因相减而消失。

### 进一步：公式、边界与追问

**技术表述：** 用 Bradley–Terry 模型 P(y_w≻y_l|x)=σ(r_w−r_l)，同题两项里的 β log Z(x) 相消。

令：

$$\Delta_\theta=\log\pi_\theta(y_w|x)-\log\pi_\theta(y_l|x)$$

$$\Delta_{\rm ref}=\log\pi_{\rm ref}(y_w|x)-\log\pi_{\rm ref}(y_l|x).$$

则：

$$L_{\rm DPO}=-\mathbb E\log\sigma\big(\beta(\Delta_\theta-\Delta_{\rm ref})\big).$$

**展开：** 标准式使用回答 token 的序列 log 概率求和；把它改成平均不是无关紧要的实现优化，而是改变目标。

**追问：实现时怎么稳？** 使用负 log-sigmoid 或 softplus(−z)，不直接先 sigmoid 再 log。

**易错：** 参考模型应固定，不让其一起朝降低 loss 的方向更新。依据：S08。

<a id="P05"></a>
## P05｜DPO 梯度在推动什么？（P0）


### 它推动的是两个回答之间的相对关系

训练希望“好答案相对差答案更占优势”。就像拉开两人的比分，既可以让领先者涨分，也可以让落后者降得更多。

因此，即使 chosen 的绝对概率下降，只要 rejected 降得更多，DPO 损失仍可能下降。模型参数互相共享，实际更新也不是两个独立概率旋钮。

**直答：** DPO 梯度推动较优与较差回答的相对 log 概率差增大；损失改善不保证每个好回答的绝对概率都逐步上升，需要联合检查生成结果。

### 进一步：公式、边界与追问

**技术表述：** 相对参考模型，提高 chosen 与 rejected 的 log 概率差；越是尚未满足偏好的样本，梯度权重通常越大。

令 z=β(Δθ−Δref)，则：

$$\nabla_\theta L=-\beta\sigma(-z)
\left[\nabla_\theta\log\pi_\theta(y_w|x)-\nabla_\theta\log\pi_\theta(y_l|x)\right].$$

**展开：** 这是单个偏好对的梯度表达。参数共享会耦合很多 token 和样本，因此不能保证每一步 chosen 的绝对概率都增加。

**追问：chosen 和 rejected 概率都降低，loss 能下降吗？** 能。如果 rejected 降得更多，相对差仍增大。应监控两边 logprob、长度和实际生成评测。

**易错：** preference accuracy 接近 100% 不证明开放生成已经优秀。依据：S08。

<a id="P06"></a>
## P06｜DPO 的参考模型究竟有什么用？（P0）


### 留一份训练前的样子，才能知道改了多少

参考模型像训练开始前的固定快照，提供“原来有多倾向这些答案”的基准。DPO 看当前模型相对这个基准的变化。

它负责提供概率，不是在评价答案好坏，所以与奖励模型不同。参考概率有时可以提前算好存下；理论上需要参考策略，并不意味着训练全过程必须额外常驻一整套模型。

**直答：** 参考模型提供固定的概率基准，让偏好优化具有相对原策略的约束含义。是否额外占用整份模型显存，要看预计算和参数共享等实现。

### 进一步：公式、边界与追问

**技术表述：** 为偏好学习提供相对基准，使目标来自一个不希望策略任意偏离原模型的 KL 正则化框架。

**展开：** 通常选择 SFT 模型。原模型本来就偏好的答案，不会仅因绝对概率高就被当成已经学会新的偏好；DPO看的是相对参考的变化。

**追问：一定额外常驻一整份参考模型吗？** 对固定数据、固定模板和固定参考模型，可以预计算参考 logprob；参数高效设置也有共享基座或切换适配器的实现。要据实际配置评估显存。

**易错：** reference、old policy、reward model 是三个不同角色。依据：S08、S51；工程预计算需确认所用训练器。

## P07｜DPO 的 β 为什么不能凭一个口诀调？（P0）


### 一个旋钮，在公式和实际训练里都有作用

β 在理想目标中控制“偏离参考模型要罚多重”。到了实际 DPO 损失，它又参与缩放偏好差值和梯度。

因此不能只背“β 大就学得更猛”或“β 大就一定更保守”，再把它当作训练结果的单调规律。学习率、数据差值和训练时长也会改变最终表现。

**直答：** β 既有 KL 权衡含义，也影响实际损失的数值尺度；调节后要观察偏好表现、分布变化和业务质量，而不是套一个口诀。

### 进一步：公式、边界与追问

**技术表述：** 理论中 β 调整奖励与偏离参考的权衡；训练实现中它也缩放偏好 logits 和梯度，效果还受数据尺度、学习率与训练时长影响。

**展开：** β 很小会使同样 log-ratio 差对应的分类 margin 小；β 很大又可能使 sigmoid 迅速饱和。不要把局部梯度现象直接等同于最终 KL 单调变化。

**追问：怎么调？** 在相同数据和预算下网格选少量 β，记录验证偏好、KL 估计、长度、通用能力和安全双侧指标。

**易错：** β=0 时标准 DPO 损失为常数 ln2，没有有效偏好梯度。依据：S08。

<a id="P08"></a>
## P08｜SimPO 的完整公式是什么？（P0）


### 两篇长短不同的回答，怎样比“模型有多愿意写”？

一句回答的总概率由每个 token 的概率相乘。越长，乘的项越多，数值往往越小。SimPO 先取 log 把乘法变成加法，再除以 token 数，比较平均分。

它直接要求较优答案的平均分比差答案更高，并希望拉开一定间隔；不再减去参考模型的分数。β 负责缩放，γ 是在缩放后分数上的间隔，所以换回原平均分单位，要除以 β。

**直答：** SimPO 直接比较好坏回答的平均 log 概率，并加入目标间隔；它不需要参考模型，但平均分仍只是训练信号，不能当成答案正确性的直接评分。

### 进一步：公式、边界与追问

**技术表述：** 用回答的平均 log 概率作为缩放后的隐式奖励，去掉参考模型，并要求偏好间有目标 margin。

$$a_\theta(x,y)=\frac{1}{|y|}\log\pi_\theta(y|x)$$

$$L_{\rm SimPO}=-\mathbb E\log\sigma\big(\beta(a_w-a_l)-\gamma\big).$$

**展开：** β 是奖励差缩放，γ 是缩放后的 margin。若写成平均 log 概率差的阈值，对应 γ/β，而非无条件等于 γ。损失是软约束，不保证所有训练对最终满足。

**追问：为什么用平均 log 概率？** 可削弱序列长度对总和尺度的影响，但不保证消除所有长度偏差，也不是直接优化事实正确率。

**易错：** 平均 log 概率的指数是几何平均概率，不是 token 概率的算术平均。依据：S09。

## P09｜用小算例比较 DPO 与 SimPO（P0）


### 总分低，可能只是算了更多项

好回答有 100 个 token，总 log 概率为 −100；差回答有 20 个，总分为 −30。直接看总分，−30 更大；按长度平均，二者是 −1 和 −1.5，好回答反而更高。

SimPO 从这些平均分构造损失；DPO 还要知道参考模型原来给了多少概率。因此只知道当前模型的这两个总分，还算不出完整 DPO 比较。

**直答：** SimPO 看当前模型的长度平均分，DPO 看相对参考模型的概率变化；同一对回答可以得到不同训练信号，不能直接比较两种 loss 数值判优。

### 进一步：公式、边界与追问

**技术表述：** DPO 比较相对参考的变化，SimPO 比较当前模型的平均 log 概率，两者可能对同一回答对给不同信号。

**教学算例：** chosen 总 logP=−100、长度 100；rejected 总 logP=−30、长度 20。平均分别为 −1 和 −1.5，差为 0.5。SimPO 取 β=2、γ=0.5，则 z=0.5，loss≈0.474。

若参考模型的总 logP 分别为 −110、−32，则当前 Δ=−70、参考 Δref=−78，DPO 取 β=0.1 得 z=0.8，loss≈0.371。

**追问：这能证明哪个算法更好吗？** 不能，两个 loss 尺度不同；应比较同条件生成任务表现。

**易错：** 不同模型/算法的训练 loss 大小不可直接排名。依据：S08、S09；数字为自建算例。

## P10｜KTO 适合什么反馈，和分类器有什么区别？（P0）


### 有时候容易判断“好不好”，却凑不成同题一对

审核日志可能只留下某个回答“可接受”或“不可接受”，没有同题另一份回答。KTO 可以利用这种单回答好坏反馈训练生成模型。

别把它理解成只训练一个“输出好坏标签”的分类器：它更新的仍然是回答各 token 的生成概率，部署时模型仍负责写答案。

**直答：** KTO 利用单个回答的好坏标签优化生成倾向，不要求每条都有同题偏好对；标签含义与数据比例仍需仔细处理。

### 进一步：公式、边界与追问

**技术表述：** KTO 用单个回答的好/坏反馈优化生成模型，不要求每条都有同题成对偏好。

**展开：** 它围绕相对参考的隐式奖励、参考点和好坏效用构造目标；好坏样本权重可不同。最终改变的是生成策略，而不是仅训练一个输出“通过/拦截”的分类头。

**追问：审核日志可以直接拿来 KTO 吗？** 先确认标签评价的是模型回答质量，还是输入风险、规则命中或审核流程结果；它们不是同一监督含义。

**易错：** 不要把 desirable/undesirable 简化成“用户请求有没有危险”，也不要混用不同时期政策标签。依据：S10。

<a id="P11"></a>
## P11｜DPO、SimPO、KTO、PPO/GRPO 怎么选？（P0）


### 先盘点手里有什么反馈

有成对好坏回答，可以先比较 DPO、SimPO；只有单条好坏记录，可以考虑 KTO；如果能不断让模型尝试，并可靠判断结果，可以进一步考虑 PPO、GRPO 等在线训练。

例如数学答案可用程序核验，和“这段话是否得体”的反馈可靠性不同。方法要配得上数据和预算。

**直答：** 先看反馈是示范、成对偏好、单条标签还是可验证结果，再选训练方法；别先选热门算法，再勉强凑它需要的数据。

### 进一步：公式、边界与追问

**技术表述：** 有成对偏好先比较 DPO/SimPO，只有单回答好坏标签可考虑 KTO；能持续采样且奖励可信，再考虑 PPO/GRPO。先匹配反馈和预算，再用任务表现选算法。

| 条件 | 候选起点 | 先验证什么 |
|---|---|---|
| 有可靠同题偏好对，预算有限 | SFT + DPO | 偏好噪声、参考实现、长度 |
| 有偏好对，想省参考相关开销 | SimPO | β/γ、遗忘、长度和实际质量 |
| 更容易获得单回答好/坏标签 | KTO | 标签语义、类别权重、参考点 |
| 能在线采样并可靠验证结果 | RLVR + 合适策略优化 | 奖励漏洞、探索、采样成本 |

**追问：你的内容安全项目为什么优先 DPO？** 按已有报告，其反馈更接近离线审核与偏好；需由真实数据构造证明。没有可靠可执行奖励时，不因 GRPO 热门而硬套。

**易错：** RLVR 是奖励/训练范式，GRPO 是优化方法，两者不是同义词。依据：S08、S09、S10、S11、S12、S13。

<a id="P12"></a>
## P12｜如何构造有价值的 rejected？（P0）


### 让学生比较“有代表性的错误”

把一篇好作文和一串乱码相比，学生很容易选对，却未必学到真实短板。更有价值的差答案可能语言流畅，只在关键事实上错误，或在边界规则上处理不当。

但也不是越难越好：如果评审者都无法稳定判断谁好谁坏，强行贴标签会引入噪声。

**直答：** rejected 应揭示模型真实、可判断的短板；兼顾代表性和标签可靠性，避免只用明显垃圾或高度争议的回答。

### 进一步：公式、边界与追问

**技术表述：** 选择能暴露当前模型真实短板、且偏好理由清楚的回答，而不是明显垃圾答案。

**展开：** 混合真实漏放/误拒、同题模型候选、边界错误、事实或策略违例；保留理由标签和置信度。控制长度、风格与固定拒答句带来的捷径。太简单提供的信息少，太模糊又增加标签噪声。

**追问：越难越好吗？** 若评审员也无法稳定排序，训练可能学到噪声。先做双标一致性、仲裁和难度分层。

**易错：** rejected 不能包含测试集专属答案或线上敏感标识而不治理。

<a id="P13"></a>
## P13｜离线 DPO 为什么仍有分布偏移？（P0）


### 改完模型，它可能写出旧练习册里没有的新答案

固定偏好集通常来自旧模型曾经生成的候选。模型变了以后，会走向新的表达、长度和边界情形，旧数据未必约束过这些情况。

重新生成、评审、补充数据可以帮助覆盖，但要付出成本，也可能把评审模型的偏见不断放大。

**直答：** 离线偏好数据只能覆盖见过的比较，更新后的模型可能生成新问题；数据收集是否在线，与使用什么损失应分开描述。

### 进一步：公式、边界与追问

**技术表述：** 固定偏好数据覆盖的是旧策略生成的候选，而训练后的模型可能生成新的、更长或更边界化的回答。

**展开：** loss 只约束被观察到的对比；在未见输出上可能出现新问题。迭代采样、重新评分并更新偏好集可以扩展覆盖，但也引入评审成本和自我强化偏差。

**追问：DPO 一定不能在线用吗？** 标准设置常是离线，但可放入迭代/在线数据收集流程；“损失形式”和“数据收集方式”分开描述。

**易错：** 不应把所有偏好优化说成从不 rollout。依据：S08、S09。

<a id="P14"></a>
## P14｜偏好优化要监控哪些指标？（P0）


### 分数表要同时看学习、行为和花费

只看偏好对上选对率，像只看学生会不会选老师批过的题。还应让模型独立回答，检查是否更会拒绝危险请求、是否也误拒正常请求，以及回答是否变长或单一。

同时记录训练用了多少时间、显存和有效 token，才能判断提升值不值得。

**直答：** 监控训练损失之外的生成行为、关键业务指标和资源成本；一个内部指标变好，不足以证明整个系统更好。

### 进一步：公式、边界与追问

**技术表述：** 同时看训练目标、分布变化、生成质量和资源成本。

**展开：** 训练看 margin、chosen/rejected logprob、偏好准确率、梯度；分布看参考 KL 估计、长度、拒答比例和多样性；业务看漏放、误拒、分类召回、帮助性；成本看显存、有效 tokens/s 与总 GPU 时。

**追问：KL 很小就一定安全？** 不保证。关键小概率行为的变化也可能很重要；平均 KL 不替代分层风险评测。

**易错：** 只挑高胜率截图，缺少冻结集、采样配置与盲评顺序，会降低结果可信度。

<a id="P15"></a>
## P15｜带噪偏好和平局怎么处理？（P1）


### 老师意见不一致，先问为什么

有的分歧来自标签标错，有的来自规则不清，有的则是两份答案各有优点。这些情况不适合都强行选一个赢家。

可以补充规则、让多人复核、记录置信度或保留平局。删掉所有难样本也可能把最重要的边界问题一起删掉。

**直答：** 先辨别反馈噪声的来源，再选择复核、软标签、权重或平局处理；不能指望更复杂的损失自动修好混乱标准。

### 进一步：公式、边界与追问

**技术表述：** 先减少标注歧义，再考虑置信度权重、软标签、噪声鲁棒目标或平局处理，不能只靠调损失补救。

**展开：** 分开“标签错”“两者都好”“两者都差”“规则矛盾”。记录标注政策、来源和多标一致性；按噪声层级做受控注入实验，观察不同目标的退化。

**追问：把所有低置信度样本删除好吗？** 可能丢掉最重要的边界场景。可用于分析或主动复核，而非全部进入强监督训练。

**易错：** label smoothing 的数值不是标注准确率的自动估计。

<a id="P16"></a>
## P16｜面试官说“DPO 只是分类”，怎么回应？（P1）


### 训练题像二选一，最后学会的仍是怎样生成

DPO 的训练形式是在判断“同题哪份回答更值得偏好”，所以损失看起来像二分类。但它的比较分数来自生成模型给回答的概率，不是随便加一个好坏分类头。

调整这些概率之后，模型自由生成时的倾向也会变化。理解这个联系比争论名字更有用。

**直答：** DPO 有分类式的偏好目标，但优化对象是生成策略的概率；其数学形式和部署时承担的生成任务要分别理解。

### 进一步：公式、边界与追问

**技术表述：** 它的偏好损失具有二分类形式，但被优化的是生成策略的序列概率；模型的生成分布会随之变化。

**展开：** 输入是一对回答，标签是偏好方向；分类 logit 由策略与参考 logprob 差构造，不是任意分类头。推理时通常只保留优化后的生成模型。

**追问：理论漂亮就保证最好吗？** 不保证，BT 偏好假设、有限策略容量、数据覆盖和优化误差都会影响结果。

**易错：** 可以承认分类式目标的工程便利，同时说明其生成策略含义，避免陷入“算不算真正 RL”的名词争论。依据：S08。

<a id="P17"></a>
## P17｜KTO 的损失与参考点具体是什么？（P1）


### 好反馈与坏反馈，推动方向相反

KTO 先比较回答在当前模型和参考模型下的概率，再与一个参考点比较。好标签希望往更受认可的方向推动，坏标签则反向推动。

它用 sigmoid 表示效用，曲线在两端逐渐变平。这意味着极端位置的梯度会变小；与交叉熵里的“负对数扣分”不是同一条曲线。KL 参考点可以先当作比较用的刻度，具体估计放在下面深读。

**直答：** KTO 用相反方向的 sigmoid 效用处理好坏标签，并引入 KL 参考点；不要把它写成普通二元交叉熵只换个标签。

### 进一步：公式、边界与追问

**技术表述：** 对好/坏样本使用方向相反的 sigmoid 效用，并与 KL 参考点比较；它不是普通二元交叉熵。

按作者 v3 的记号：

$$r=\log\frac{\pi_\theta(y|x)}{\pi_{\rm ref}(y|x)}$$

$$z_0=D_{\rm KL}(\pi_\theta(\cdot|x)\|\pi_{\rm ref}(\cdot|x)).$$

$$L_D=\lambda_D[1-\sigma(\beta(r-z_0))]$$

$$L_U=\lambda_U[1-\sigma(\beta(z_0-r))].$$

**展开：** 数据集按好坏标签选择对应项并平均。β 放在效用里，r 本身没有再乘 β，避免重复缩放。原文实现用批内错配输入/回答估计共享参考点并截到非负，不反传该项；这不是精确词表 KL。

**追问：和 −log σ 有何不同？** sigmoid 效用在极端两侧会饱和，梯度趋小；不能把它当 BCE 只换一下标签。

**易错：** 参考点估计与好坏权重属于目标的一部分，换实现需记录。依据：S10，正文式 8 与 KL Estimate。

<a id="P18"></a>
## P18｜显式奖励模型如何训练和验证？（P0）


### 给作文评分的老师，也需要考试

奖励模型学习给回答一个标量分数。常见训练让同题较优回答分高、较差回答分低，反复学习评审者的偏好。

但生成模型会主动寻找能拿高分的答案，可能钻评分规则的漏洞。奖励模型在旧作业上判得准，不代表遇到这些新花样仍可靠。

**直答：** 奖励模型从偏好学习评分，再用于指导生成模型；需要独立验证其排序和抗投机能力，不能只看训练偏好准确率。

### 进一步：公式、边界与追问

**技术表述：** 用同题偏好训练标量评分 rφ，使好回答分数高于差回答，再独立验证排序、校准与抗投机能力。

$$L_{\rm RM}=-\mathbb E\log\sigma(r_\phi(x,y_w)-r_\phi(x,y_l)).$$

**展开：** 这是常见 BT 偏好目标；模型可在语言模型表征上接评分头。奖励的绝对零点通常不可由成对差唯一确定；不同任务分数尺度也不天然可比。

**追问：奖励模型训练准确率高，策略训练就安全吗？** 策略会主动寻找高分输出，可能进入评分器没见过的区域。需要生成后重评、长度/风格反例及独立人工或可执行校验。

**易错：** 相同训练集上的 reward accuracy 不能证明真实奖励可靠；DPO 隐式奖励也不能直接当作已校准业务风险概率。依据：S08、S52。
