# 15 传统机器学习与 NLP 基线

简单模型是理解与实验的好起点。先看它使用什么特征、怎样判断，再与大模型比较。不需要因为模型传统就忽略它，也不必因此把所有任务都交给简单模型。

<a id="B01"></a>
## B01｜逻辑回归为什么叫回归却用于分类？（P0）


### 先算分，再变成属于某一类的概率

逻辑回归把输入特征加权求和，再用 sigmoid 转成 0 到 1 的数。例如根据若干文本特征估计是否属于某类别，最后按阈值分类。

“回归”出现在名称里，不妨碍它用于分类；重点看模型输出和训练目标。

**直答：** 逻辑回归用线性特征得分建模类别概率，再根据阈值决策，是常见、可解释的分类基线。

### 进一步：公式、边界与追问

**本章进阶约定与范围：**

定位：为通用算法面试补底，也帮助你证明使用大模型的必要性。不要丢掉简单、便宜且可解释的强基线。

**技术表述：** 它对类别的 log-odds 做线性建模，再经 sigmoid 转成概率。

$$\log\frac{p}{1-p}=w^\top x+b,\quad p=\sigma(w^\top x+b).$$

**展开：** 用二元交叉熵训练，决策边界在特征空间中为超平面。加入 n-gram、非线性特征后，可处理原输入上的复杂模式。

**追问：输出是否天然校准？** 在模型设定与数据条件匹配时有优势，但现实数据偏移和正则化仍会影响校准。

**易错：** 不要把类别不均衡的阈值固定为 0.5 当作业务最优。

<a id="B02"></a>
## B02｜LR 与 SVM 如何比较？（P1）


### 估计哪边概率大，还是找一条分隔余量大的线？

逻辑回归直接学习类别概率相关的目标；SVM 重点寻找能把类别分开、并留出较大间隔的边界。

SVM 的决策分数不天然等于校准后的概率。两者都应放在同样的数据、特征和调参预算下比较。

**直答：** LR 与 SVM 的目标和输出解释不同；根据概率需求、特征和任务表现选择，不以算法名称直接判优。

### 进一步：公式、边界与追问

**技术表述：** LR 学条件概率并用 log loss；SVM 通过 margin 与 hinge loss 强调决策边界。实际选型需比较数据与成本。

**展开：** 线性 SVM 在高维稀疏文本上可作基线；核方法能表达非线性，但大样本训练/推理成本要考虑。概率输出通常需额外校准。

**追问：SVM 只关心支持向量是什么意思？** 最优解受到边界附近约束的关键样本影响；具体还取决于软间隔与损失。

**易错：** 不能绝对说一种永远优于另一种。

<a id="B03"></a>
## B03｜TF-IDF + 字符 n-gram 为什么值得做？（P0）


### 简单数片段，也可能抓住很多有用线索

“我爱学习”的字符 2-gram 是“我爱、爱学、学习”。把文本里出现的这些片段当作特征，再用 TF-IDF 降低到处都出现的词项的影响。

这种方法便宜、便于检查，也能捕捉局部字符模式，但不擅长长距离语义和复杂推理。

**直答：** TF-IDF 与字符 n-gram 提供低成本、可解释的文本特征，应作为简单基线比较，并分析其局部模式局限。

### 进一步：公式、边界与追问

**技术表述：** 计算便宜、能捕获局部变体、可检查高权重特征，是中文短文本安全分类的有价值基线。

**展开：** TF 表示文档内词项强度，IDF 降低常见项权重。字符片段可处理部分空格、拼写与字母组合，但不擅长长语境和复杂意图。

**追问：怎样防止特征泄漏？** 词表与 IDF 只在训练集拟合，不能先用全量数据 fit 后再切分。

**易错：** n 越大模式更长，也更稀疏；不存在脱离数据的最佳 n。依据：S67。

<a id="B04"></a>
## B04｜Word2Vec、静态向量与上下文表示区别？（P1）


### “苹果”在水果文章和手机文章里，应该一样吗？

静态词向量通常给同一个词固定表示，难以区分此刻说的是水果还是公司；上下文表示会结合周围文本改变这个位置的表示。

Word2Vec 通过词的共现学习静态向量，是理解词表示的经典起点。

**直答：** 静态向量主要按词表项给表示，上下文模型按当前语境给位置表示，因此更有机会区分一词多义。

### 进一步：公式、边界与追问

**技术表述：** 静态词向量通常一个词一份表示；上下文模型根据具体句子动态生成表示。

**展开：** Skip-gram 用中心词预测上下文；CBOW 用上下文预测中心词。负采样用少量负例近似训练目标，但不应说它精确计算完整 softmax。

**追问：为什么向量相似不等于语义相同？** 反义词也可能出现在相似语境；任务需要可能与共现相似不同。

**易错：** 词向量类比现象不是可靠知识推理能力的证明。依据：S76。

<a id="B05"></a>
## B05｜决策树、随机森林、GBDT 的区别？（P1）


### 一套问答规则、很多人投票、不断补前人的错

决策树通过连续条件判断作出预测；随机森林训练多棵有差异的树并汇总；GBDT 则逐步增加模型，补偿当前预测的误差。

“很多棵树”不代表训练方式相同，要区分并行集成与依次纠错的思想。

**直答：** 决策树是单个规则结构，随机森林通过差异化树集成降低波动，GBDT 逐步拟合剩余误差提高表现。

### 进一步：公式、边界与追问

**技术表述：** 树通过特征切分建立规则；随机森林训练多棵较独立的随机树并聚合；GBDT 逐轮拟合现有模型的误差方向。

**展开：** 表格元数据，如长度、风险分数、来源、历史命中，可用树模型建立强基线；原始长文本通常先做特征或表示。

**追问：特征重要性可靠吗？** 受相关特征、分裂偏好和数据泄漏影响；可辅以置换与受控删除评测。

**易错：** boosting 不等于把多棵树简单平均。

## B06｜类别不平衡怎样处理？（P0）


### 只说“都正常”，也可能拿到很高准确率

若 99% 样本都是正常，全部预测正常就有 99% 准确率，却一个风险也没找回。类别不平衡会让总指标掩盖少数类失败。

可以调整采样、损失权重和阈值，但都要看少数类召回、误报与概率校准，而不是只提高某个数。

**直答：** 先选能暴露少数类表现的指标，再比较数据、损失和决策层面的处理，联合控制漏检与误报。

### 进一步：公式、边界与追问

**技术表述：** 结合采样、损失权重、数据补充与决策阈值，并用真实部署分布评测。

**展开：** 过采样少数类增加其训练权重，也可能重复记忆；加权损失会改变概率解释，需校准。Focal loss 强调难样本，但噪声标签也可能被放大。

**追问：训练均衡、线上极不均衡怎么办？** 测真实基率下 precision、复核成本与风险，不只在人工均衡集报 accuracy。

**易错：** 测试集重新平衡后不能直接代表真实误报负担。

<a id="B07"></a>
## B07｜过拟合如何定位？（P0）


### 记熟练习题，却不会做同类新题

训练集越来越好，独立验证集却停滞或变差，是过拟合的常见信号。原因可能是数据少、重复多、模型过度适应或验证分布不同。

应先排除泄漏和切分问题，再考虑增加有效数据、正则化、简化模型或早停。

**直答：** 过拟合是对训练材料适应过强、泛化不足；通过独立评测和学习曲线定位，再针对数据或训练复杂度处理。

### 进一步：公式、边界与追问

**技术表述：** 看训练与独立验证的差距，再排数据泄漏、分布不同和指标实现错误。

**展开：** 控制容量、正则化、早停、数据增强与更多独立样本都可帮助，但应该针对原因。学习曲线能显示是否主要受数据量或模型能力限制。

**追问：训练好验证差一定是过拟合？** 可能是训练/验证预处理不一致或领域漂移，应先核查。

**易错：** 重复数据扩增后的样本数不等于独立信息量增加。

## B08｜如何公平比较传统模型与大模型？（P0）


### 比赛要给双方合理的参赛条件

不能给大模型精心设计提示、充分调参，却给传统模型随便一组默认特征，就宣布后者无用。也不能忽略大模型更高的推理成本。

同时报告效果、时延、资源、维护和样本需求，才能回答业务上该选哪个。

**直答：** 在相同数据切分和合理调参条件下比较方法，并把质量与完整成本一起报告。

### 进一步：公式、边界与追问

**技术表述：** 同一冻结数据、相同标签政策与业务约束，比较质量、速度、成本、维护和长尾行为。

**展开：** 内容安全可依次比较规则、TF-IDF+LR、encoder 分类器、LLM 分类/生成策略。每层回答“新增复杂度解决了哪类失败”。

**追问：如果传统模型更好怎么办？** 保留它作为生产组件或前置筛选，把大模型用于真正需要语境和开放生成的部分。

**易错：** 为证明大模型必要而只选一个没有调优的弱基线，会削弱面试可信度。
